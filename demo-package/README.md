# חבילת הדגמה — מועדון אופק העיר

כל הנתונים בחבילה פיקטיביים ומיועדים לצילום סרטון הדרכה בלבד.

## סדר טעינה לצילום

1. התחברו כאדמין ובצעו **הגדרות → איפוס סביבת העבודה**.
2. בהגדרות הגדירו שם מועדון, צבעי מועדון ולוגו משלכם.
3. בסגל בחרו **ייבוא CSV** וטענו את `../sample-imports/demo-squad-24-season-stats.csv`.
4. במשחקים בחרו **ייבוא CSV** וטענו את `demo-matches-36.csv`.
5. פתחו את **המשחק הבא**, בחרו את משחק הליגה המתוכנן ובנו הרכב.
6. עברו אל **סטטיסטיקות** והציגו את הנתונים המצטברים או בחרו שחקן בודד.

## לפני הטעינה

יש להריץ ב־Supabase SQL Editor, לפי הסדר, את:

- `202608020004_imported_season_statistics.sql`
- `202608020005_idempotent_player_import.sql`

לאחר מכן עמודות נתוני העונה בקובץ הסגל נשמרות ומוצגות בסגל ובדשבורד הסטטיסטיקות. טעינה חוזרת של אותו קובץ מעדכנת את השחקנים במקום ליצור כפילויות.
